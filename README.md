## How I think about engineering

A few principles that guide my work:

- **Evidence before autonomy.**
- **AI is a system, not a prompt.**
- **Observability by design.**
- **Human control belongs in the architecture.**
- **Documentation is engineering.**
- **Boundaries should make systems easier to replace, test and evolve.**
